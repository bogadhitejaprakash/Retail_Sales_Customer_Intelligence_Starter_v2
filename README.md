# Retail Sales & Customer Intelligence

An interactive retail analytics portfolio project built with **Python, Pandas and Streamlit**, designed to explore sales performance, customer behaviour and business KPIs.

### Live Dashboard

[View Interactive Dashboard](https://retailsalescustomerintelligencestarterv2-ggpmnhwprvysz6dbnr7wt.streamlit.app/)

### Technologies
- Python
- Pandas
- Streamlit
- SQL
- Git and GitHub

### Current Features
- Sales revenue analysis
- Completed invoice tracking
- Average order value
- Identified customer counts
- Country filtering
- Monthly sales visualisation

### Dataset

The current deployed version uses fictional practice transactions for educational purposes. A future version will incorporate the UCI Online Retail dataset for more comprehensive analysis.

### Project Status

**Version 1:** Practice dataset, initial analytics and deployed dashboard.

**Next:** Real-world data cleaning, exploratory data analysis, customer segmentation and enhanced visualisations.
